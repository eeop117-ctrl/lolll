# Windows 12 — веб-версия

Интерактивная имитация операционной системы Windows 12 в браузере. Чистый HTML/CSS/JavaScript, без зависимостей и сборки.

Это независимый веб-концепт, не продукт Microsoft и не настоящая ОС.

## Если Windows не распознаёт cygpath

В `build.bat` путь проекта преобразуется командой `cygpath.exe`. В этой версии исправлено quoting этой команды, поэтому пути с кириллицей в имени пользователя должны обрабатываться корректно.

## Запуск

**Вариант 1** — просто откройте `index.html` двойным щелчком.

**Вариант 2** — через локальный сервер (рекомендуется, нужен Node.js):

```bash
npm start
```

и откройте http://localhost:8080

## Что внутри

- Загрузка, экран блокировки с погодой, вход (можно задать пароль), выключение, перезагрузка, спящий режим
- Рабочий стол: значки, выделение рамкой, перетаскивание, контекстное меню, импорт файлов перетаскиванием с компьютера
- Окна: перемещение, изменение размера, прикрепление к краям, макеты прикрепления (наведите на «Развернуть»), сворачивание в панель задач
- Плавающая панель задач, меню «Пуск» с поиском (и калькулятором прямо в поиске), быстрые настройки, центр уведомлений с календарём, виджеты, представление задач и виртуальные рабочие столы
- Приложения: Проводник, Параметры, Браузер, Блокнот, Калькулятор, Paint, Терминал, Диспетчер задач, Фотографии, Медиаплеер, Часы, Календарь, Погода, Сапёр, 2048, Ассистент, Камера
- Все файлы и настройки сохраняются в браузере (localStorage); есть экспорт/импорт резервной копии в «Параметрах»

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+S | Меню «Пуск» |
| Ctrl+Alt+D | Показать рабочий стол |
| Ctrl+Alt+E / I / T / K | Проводник / Параметры / Терминал / Ассистент |
| Ctrl+Alt+V | Представление задач |
| Ctrl+Alt+← → ↑ ↓ | Прикрепить / развернуть окно |
| Ctrl+Alt+W | Закрыть окно |
| Ctrl+Alt+L | Заблокировать |
